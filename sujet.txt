# ft_search

Retrouve un nombre dans un tableau trié grâce à la recherche dichotomique.

## Le tableau

```c
int tab[] = {
    2, 5, 9, 14, 18,
    23, 31, 37, 42,
    50, 61, 74, 89
};
```

## Règles

- Le tableau est déjà trié.
- Le joueur entre un nombre.
- Le programme doit retrouver ce nombre en utilisant uniquement une recherche dichotomique.
- Si le nombre est trouvé, afficher son index.
- Sinon afficher "Nombre introuvable."
- À la fin, proposer une nouvelle recherche (`o`/`n`).

## Contraintes

- Pas de `for`, pas de `switch`, pas de variables globales.
- La recherche doit obligatoirement être dichotomique.
- Une recherche linéaire est interdite.
- Ne doit jamais crash.
- Makefile avec `$(NAME)`, `all`, `clean`, `fclean`, `re`.

## Exemple

```
Tableau chargé !

Nombre à rechercher : 42

Trouvé !
Index : 8

Rechercher un autre nombre ? (o/n) : o

Nombre à rechercher : 10

Nombre introuvable.

Rechercher un autre nombre ? (o/n) : n
```

- Générer automatiquement un tableau trié de 100 nombres.
